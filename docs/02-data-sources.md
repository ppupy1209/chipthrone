# 데이터 소스

## Hyperliquid 24시간 추정 시세

- `POST https://api.hyperliquid.xyz/info`
- body: `{"type":"metaAndAssetCtxs","dex":"xyz"}`
- `markPx`를 추정 USD 가격, `prevDayPx`를 API `changePct`(24시간 등락률)의 기준가로 쓴다.
- 국내 두 종목은 `xyz:SMSN`, `xyz:SKHX`다.
- 지원 미국 종목은 반도체·M7 카테고리로 제공하며, 어느 카테고리에도 없는 지원 종목은 "기타"로 자동 분류된다. 같은 종목이 여러 카테고리에 있어도 구독은 한 번만 센다.

### 미국 종목 종가 기준용 과거 캔들

- `POST https://api.hyperliquid.xyz/info`
- body: `{"type":"candleSnapshot","req":{"coin":"xyz:NVDA","interval":"15m","startTime":…,"endTime":…}}`
- 응답 각 원소의 `T`가 캔들 마감 시각(ms)이다. 요청 시각 이전에 마감된 것 중 가장 늦은 캔들의 `c`를 쓴다.
- 직전 미국 정규장 마감(16:00 ET)을 요청 시각으로 삼아 미국 카드의 종가 대비 등락률 기준가를 구한다.
- 종목별로 마감 기준일이 바뀔 때만 1회 호출한다. 폴링 주기와 무관하다.
- 이는 공개 파생시장 가격이며 미국·한국 거래소의 주식 체결가가 아니다.

API는 universe 전체를 한 번에 반환한다. 따라서 사용자 200명이 같은 종목을 봐도, 서로 다른 종목을 봐도 polling cycle당 외부 호출은 batch 1회다. 구독자가 없으면 15초 grace 이후 호출하지 않는다.

## 업비트 KRW-USDC 원화 환산

- `GET https://api.upbit.com/v1/orderbook?markets=KRW-USDC&count=1`
- 인증키가 필요 없는 공개 시세 조회 API를 백엔드에서만 호출한다. 브라우저 요청에 붙는 `Origin` 헤더도 전송하지 않는다.
- 최우선 매수 호가와 매도 호가의 중간값을 USD/KRW의 근사값으로 사용한다. USDC 시장가는 공적 환율이 아니며 원화 프리미엄과 USDC 가격 변동이 반영될 수 있다.
- 5분 동안 값을 재사용하므로 상시 구독 상태에서도 최대 288회/일만 호출한다. 업비트의 시세 조회 한도인 초당 10회보다 충분히 낮은 수준이다.
- 호가 갱신이 15분보다 오래됐으면 사용하지 않는다. 5분 사이 환산값이 5% 넘게 바뀌어도 거부한다. 조회 실패 시 최근 30분 이내의 마지막 성공값만 유지한다.
- 업비트 원본 응답과 환율값은 외부 API와 화면에 노출하지 않는다. 화면에는 환산된 해외 추정값만 표시한다.

환경변수: 없음. 필요하면 `UPBIT_API_URL`, `UPBIT_MARKET`으로 덮어쓴다.

업비트 Open API 약관은 데이터의 무단 사용과 변경을 제한한다. 따라서 원본 시세를 재배포하지 않고 내부 환산에만 사용한다. 상업 서비스로 범위를 넓히기 전에는 별도 사용 허가 확인이 필요하다.

## 호출·캐시 정책

| 소스 | 호출 단위 | 정책 |
|---|---|---|
| Hyperliquid | 전체 universe batch | 활성 종목이 있을 때 3초당 1회 |
| 업비트 | KRW-USDC 단일 페어 | 5분 캐시, 실패 시 10분 재시도, 최근 성공값은 최대 30분 유지 |

## 제외한 소스: 금융위원회 일별 주식시세정보

2026-09-14에 이 소스를 제외하면서 전날 종가, 확정 시가총액, 마감 시점 괴리율, 국내 카드의 종가 대비 등락률도 함께 제거했다.

- 공공데이터포털 `금융위원회_주식시세정보`의 이용허락범위는 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지)이며, 무단 제3자 제공과 재배포를 금지한다. 상업적 이용은 KRX Data Marketplace에서 데이터를 구매해야 가능하다.
- 원천이 한국거래소 시세라 무료 대체 경로도 같은 제한을 받는다. KRX Open API는 제3자 제공을 금지하고, 한국투자증권 KIS Developers는 제3자 서비스에 코스콤 정보이용계약을 요구한다. Twelve Data와 EODHD의 개인 요금제도 재배포와 공개 표시를 허용하지 않는다.
- 왕좌 판정과 역전 조건은 Hyperliquid 추정 시가총액으로 계산한다. 국내 종목 상장주식수는 `application.yml` 고정값이라 자기주식 소각이나 신주 상장이 있으면 직접 갱신한다.

KIS, Alpaca, 증권사 투자의견 API는 현재 실행 경로에 없다. Toss Open API는 승인 후 약관상 시세 표시·제3자 제공 허용 범위를 먼저 확인해야 한다.
